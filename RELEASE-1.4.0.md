# Записки фельдшера 1.4.0 — МКБ

## Изменения

- Отдельный пункт меню «МКБ». Препараты не перерабатывались.
- Офлайн-иерархия из ФРНСИ 2.27: 22 класса, группы, категории и уточнения. Порядок групп — по коду.
- Код и официальное название копируются вместе нажатием на заголовок карточки.
- Один поисковый движок для справочника и блока «Диагноз»; вся фраза, окончания, синонимы, распространённые сокращения, одна опечатка с явной пометкой.
- В карте предлагаются только конечные рубрики, без дочерних кодов. Трёхзначный код допустим, если это конечная рубрика (например I10).
- «!» необязателен; он начинает новый поисковый фрагмент внутри свободного текста. Неизвестные значимые слова не отбрасываются.
- Стадия/степень не выбирает автоматически поражение органа. Для «холецистопанкреатита» явно предлагаются компоненты, не выдуманный единый код.
- Ссылки на ранее выбранные коды продолжают использовать прежние идентификаторы.

## Клиническое наполнение и ограничения

35 оригинальных тематических справок, прикреплённых к 299 рубрикам. Это НЕ 299 независимо подготовленных протоколов и НЕ полное клиническое покрытие 15 038 рубрик. Общая справка по группе явно обозначена. Для остальных кодов остаются классификатор и навигация, без выдуманных назначений.

Поля: объяснение, симптомы, опасные признаки, тактика, препараты по показаниям, источники и дата просмотра. Использованы рекомендации РФ в опубликованной копии MedElement, ВОЗ, NICE, RCUK, CDC, NHS, Johns Hopkins и профессиональный справочник MSD. Тип источника показан в каждой карточке. Международный материал не выдаётся за протокол СМП РФ. Полные тексты источников не копировались.

Справки не прошли независимую клиническую рецензию. Они не заменяют действующий локальный алгоритм, инструкцию препарата и клиническую оценку. Не представляют собой дозовый лист назначений. Дозы детям из взрослых схем не экстраполируются. Клинические советы не генерируются во время поиска.

## Сохранность

Версия приложения: versionCode 14. Схема личной базы вызовов и миграции не изменялись. Классификатор и клинические справки независимы от записей пользователя. Не удалять прежнее приложение перед установкой обновления. До установки желательно экспортировать личные данные из приложения.

Архив проекта — не резервная копия вызовов на телефоне: доступа к ним нет. Приватный архив содержит ключ подписи для совместимых обновлений; его нельзя публиковать в открытом репозитории.

## Проверки

По просьбе пользователя сначала собирается и сохраняется APK с архивом проекта, затем запускаются тесты. Итоговые результаты будут записаны в QA-1.4.0.md. До появления этого отчёта сборку нельзя считать проверенной.
