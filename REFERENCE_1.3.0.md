# Справочник и ссылки в записи — 1.3.0

## Что изменено

- Исправлено несовпадение формата файла ГРЛС: исходный код ожидал `.db.gz`, присланный APK содержал `.db`. Старый репозиторий понимает оба варианта; новый интерфейс использует отдельный проверяемый индекс.
- 4 134 группы лекарственных препаратов/комбинаций из предоставленной выгрузки ГРЛС. Поиск по МНН, торговым названиям, проверенным бытовым и латинским синонимам. Комбинированные препараты не объединяются с монопрепаратами.
- Убраны промышленные субстанции и повторы размеров вторичной упаковки. Формы сохраняют исходные концентрации, объёмы и пути введения. Для каждой формы перечислены соответствующие торговые названия.
- 29 кратких клинических справок для частых препаратов. Это не 4 134 готовых протокола лечения: у остальных карточек есть регистрационные сведения и фармакотерапевтическая группа, отсутствие клинической справки явно указано.
- Латинские названия выводятся только из проверенного словаря. Сведения о дозах и разведении привязаны к указанной форме/инструкции. Объём упаковки не выдаётся за введённую пациенту дозу.
- Избранное и последние открытые карточки, отдельные вкладки препаратов и МКБ-10.
- Блок «Препараты»: подсказки по тексту перед курсором, выбор формы/концентрации/объёма, вставка ссылкой, сохранение свободного текста и переносов строк.
- Новый необязательный блок «Диагноз»: подсказки классификатора, код в записи, произвольные формулировки без кода, несколько диагнозов в одном тексте.
- Поиск «гипертонич…» показывает семейство I10–I15 с конкретными названиями; код выбирает пользователь. При вводе «и11.9» распознаётся I11.9.
- Ссылки открывают карточку поверх записи. Ручная правка подписи ссылки превращает её в обычный текст; остальные ссылки сдвигаются вслед за текстом.

## Сохранность записей

Идентификатор приложения и ключ подписи сохраняются. Версия базы Room остаётся 3: новые сведения хранятся в существующем JSON блоков, без пересоздания таблиц. `text` остаётся обычным текстом, `references` хранит проверяемые диапазоны и стабильные ID справочника. Текст и ссылки меняются одним сохранением черновика.

`backup.json` сохраняет оба поля. В читаемый TXT выводится текст без служебного JSON ссылок. Старые записи без поля ссылок открываются как раньше. После создания новых блоков «Диагноз» не следует откатываться на старый APK, который не знает этот тип блока.

## Источники

Формы и названия — исходная поставленная база ГРЛС 18.09.2026; классификатор — поставленный ФРНСИ МКБ-10 2.27. Пересборка индекса: `python tools/build_medicine_index.py`. Каждая клиническая справка содержит URL источника в `ClinicalGuides.kt` и доступную в интерфейсе ссылку. Краткие справки не являются полными инструкциями: возраст, показание и конкретную упаковку необходимо сверять при назначении.
