# 1.3.1 — удобный поиск в записи

- Диагноз ищется целой фразой, без отбрасывания первых слов. Учитываются окончания слов, порядок слов и офлайн-синонимы.
- `!` начинает новый запрос в текущей строке. При выборе заменяется только запрос с маркером; предыдущий текст сохраняется. Без выбора текст остаётся свободным.
- В карте выдаются только активные конечные узлы МКБ, включая полноценные трёхзначные коды без дочерних рубрик. Группы остаются в справочнике.
- Добавлена кнопка «Ещё варианты». Выбор диагноза всегда ручной; поисковый словарь не устанавливает диагноз и не понимает произвольный клинический рассказ как врач.
- Объединены карточки с отсутствующим МНН, когда торговое имя точно совпадает с известным веществом. Объединены варианты наименования магния сульфата и парацетамола. Составы комбинаций нормализованы по порядку ингредиентов; разные составы не объединяются.
- Комбинации скрыты из обычного поиска вещества, доступны переключателем и по собственному торговому названию.
- Фильтр форм: инъекции, таблетки/капсулы, другие. Концентрации и пути введения не объединяются.
- Старые ссылки и избранное преобразуются к объединённым карточкам. Личная база и формат записей не изменены.

Источники: официальный текст кодов берётся из встроенной ФРНСИ МКБ-10 РФ 2.27. Поисковые синонимы не заменяют этот текст. Для проверки значения G93.0/Q04.6: https://gesund.bund.de/en/icd-code-suche/g93-0 и https://gesund.bund.de/en/icd-code-suche/q04-6. Магния сульфат: https://www.rlsnet.ru/active-substance/magniya-sulfat-1442.

Порядок выдачи: сначала APK и резервный архив исходников, затем регрессионные тесты. Архив проекта не является копией вызовов с телефона: такие записи доступны только на самом устройстве.
